>본 분석에서는 Yahoo Finance를 통해 테슬라(Tesla)와 현대자동차(Hyundai)의 일별 주가 데이터를 수집. 분석 기간은 2021년 1월부터 2025년 12월까지이며, 두 종목의 비교 가능성을 위해 공통 거래일의 조정 종가 데이터를 사용하였습니다. 데이터 다운로드 후 종가 데이터를 추출하고 결측치를 확인 및 결측치가 존재하는 경우 두 종목 모두 가격이 존재하는 날짜만 분석에 사용하였습니다.

#

# 1. 과제 개요

본 프로젝트는 미국의 테슬라(Tesla)와 한국의 현대차(Hyundai Motor)의 주가 데이터를 활용하여 두 기업의 주가 변동성을 비교·분석한 시계열 데이터 분석 입니다.

2021년 1월부터 2025년 12월까지의 일별 주가 데이터를 이용하여 일간 수익률, 변동성, 이동 변동성 등을 분석하고 두 종목의 주가 움직임에 어떤 차이가 나타나는지 확인했습니다.

# 1-1. 분석 목적

 두 종목의 주가 데이터를 동일한 기간과 기준으로 비교하여 다음과 같은 내용을 확인하는 것을 목적으로 합니다.

- 두 종목의 주가 흐름에는 어떤 차이가 있는가?

- 두 종목의 일간 수익률과 변동성은 어떻게 다른가?

- 시간에 따라 변동성이 어떻게 변화했는가?

- 두 종목의 주가 변동이 서로 비슷하게 움직이는 시기가 있었는가?

# 1-2. 데이터

- 데이터 출처: Yahoo Finance

- 데이터 수집 라이브러리: yfinance

- 분석 기간: 2021-01-01 ~ 2025-12-31

- 실제 공통 거래일: 2021-01-04 ~ 2025-12-30

- 종목
     - Tesla: TSLA
     - Hyundai Motor: 005380.KS

- 데이터 단위: 일별 주가

- 주요 분석 변수: 종가(Close), 일간 수익률

>미국과 한국의 거래일이 서로 다르기 때문에 두 종목의 가격 데이터가 모두 존재하는 날짜만 남겨 공통 거래일을 기준으로 분석했습니다.

# 1-3. 분석 방법

1. **일별 주가 데이터 수집**

2. **결측치 및 데이터 이상 여부 확인**

3. **공통 거래일 기준 데이터 정리**

4. **일간 수익률 계산**

5. **전체 기간의 변동성 비교**

6. **30일 이동 변동성 분석**

7. **연도별 변동성 비교**

8. **60일 이동 상관관계 분석 주가 및 수익률 시각화**

# 5. 참고 사항

>본 분석은 과거 주가 데이터를 대상으로 한 시계열 분석이며, 분석 결과가 미래의 주가 움직임이나 투자 결과를 보장하는 것은 아닙니다. 또한 거래일 차이로 인해 두 종목의 공통 거래일만 사용했으므로 원본 데이터 전체와 분석 데이터의 관측치 수에는 차이가 있습니다.
